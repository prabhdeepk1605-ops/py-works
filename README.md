# Sum API Flask Example

Run a tiny Flask app that serves `index.html` and exposes an API to sum two numbers.

Setup and run:

```bash
python -m venv .venv
.
\# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Open http://127.0.0.1:5000/ in your browser, enter two numbers, and click Calculate.
